# 요구사항 명세

기준 문서: docs/plan.md (폭염지킴이)
이번 라운드 범위: 근처 쉼터 찾기 화면(네이버 지도 연동)

(체크인 화면은 방향 전환으로 제거함)

## 1. 화면 목록

### ① 근처 시설 찾기 화면 (메인)
- "오늘 폭염특보 확인" 버튼 — 기상청 폭염 특보 페이지(weather.go.kr)로 새 탭 이동
- "근처 무더위쉼터 찾기" / "근처 동사무소 찾기" / "근처 면사무소 찾기" / "근처 시청 찾기" / "근처 버스정류장 찾기" 버튼 5개가 보임
- 버튼을 누르면 브라우저가 현재 위치 권한을 요청함
- 위치를 확인하면 새 탭에서 해당 키워드의 네이버 지도 검색 결과를 현재 위치 근처로 열어줌
- 위치 확인이 안 되면 위치 없이 전체 검색 결과를 열어줌
- 네이버 지도 API 키가 필요 없음 (네이버 지도 웹 검색 링크로 연결하는 방식)
- 버튼 아래에 네이버 지도 앱 설치 링크(구글플레이, 앱스토어) 표시 — 앱이 없는 사용자를 위한 안내
- "긴급 연락처" 섹션 — 119(화재·구급), 112(경찰), 치매상담콜센터(1899-9988), 보건복지상담센터(129) 버튼. 누르면 바로 전화가 걸림 (tel: 링크)
- 로그인 없이 누구나 접근 가능

## 2. 기능 목록 (사용자가 할 수 있는 행동)

- "오늘 폭염특보 확인" 버튼을 눌러 기상청 특보 페이지를 본다
- 5개 버튼(무더위쉼터/동사무소/면사무소/시청/버스정류장) 중 하나를 누른다
- 위치 권한을 허용하면 네이버 지도에서 근처 검색 결과를 새 탭으로 본다
- (네이버 지도 화면에서) 목록 중 원하는 곳을 눌러 도보 길찾기를 시작한다 — 이 마지막 단계는 네이버 지도 자체 기능이라 우리 화면에서 자동화하지 않음
- 네이버 지도 앱이 없으면 구글플레이/앱스토어 설치 링크를 누른다
- "검색 결과를 거리순으로 보는 방법" 버튼을 누르면 네이버 지도 안에서 정렬을 거리순으로 바꾸는 방법 안내가 펼쳐진다
- "서류 발급 준비" 버튼(장소 찾기 버튼들과 같은 크기, 별도 섹션으로 구분)을 누르면 문서 10종 버튼이 나오고, 그중 하나를 누르면 그 문서의 필요한 것/발급 방법/발급 창구가 바로 아래에 펼쳐진다
- 어르신들의 눈 건강을 고려해 전체 글자 크기를 키움
- "긴급 연락처" 버튼을 누르면 해당 번호로 바로 전화가 걸린다

## 3. 데이터

이 화면은 네이버 지도 검색으로 바로 연결되기 때문에, 저장하는 데이터가 없음.

## 4. 이번에 만들지 않을 것

- 로그인 / 회원가입
- 체크인, 관리자 대시보드 (방향 전환으로 제거)
- 네이버 지도 API 직접 연동 (Client ID 발급, Dynamic Map, Directions API) — 대신 네이버 지도 웹 검색 링크로 대체
- 실제 지자체 공공데이터 연동
- 데이터베이스 연동 (Supabase 등)
