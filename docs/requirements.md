# 요구사항 명세

기준 문서: docs/plan.md (폭염지킴이)
이번 라운드 범위: 쉼터 지도 화면, 체크인 화면 (로그인 없는 간단한 방식)

## 1. 화면 목록

### ① 쉼터 지도 화면
- 진주시 경로당·동/주민센터 위치를 지도에 마커로 표시
- 마커를 클릭하면 이름, 종류(경로당/동주민센터), 주소가 보임
- 로그인 없이 누구나 접근 가능

### ② 방문 대상자 체크인 화면
- 방문이 필요한 대상자 이름 목록이 보임
- 각 이름 옆에 "오늘 확인 완료" 체크박스가 있음
- 체크된 사람은 체크한 시각이 표시됨
- 로그인 없이 누구나 접근 가능 (정식 인증 없음)

## 2. 기능 목록 (사용자가 할 수 있는 행동)

- 지도에서 근처 쉼터 위치를 확인한다
- 쉼터 마커를 눌러 이름·종류·주소를 본다
- 체크인 화면에서 대상자 목록을 본다
- 대상자의 체크박스를 눌러 "오늘 방문 확인"으로 표시한다
- 체크한 시각이 자동으로 기록되어 목록에 함께 보인다

## 3. 데이터 (표 형태)

### 쉼터 (Shelter)

| 필드 | 타입 | 설명 |
|---|---|---|
| id | 문자열 | 고유 식별자 |
| name | 문자열 | 쉼터 이름 (예: OO경로당) |
| type | 문자열 | "경로당" 또는 "동주민센터" |
| address | 문자열 | 주소 |
| lat | 숫자 | 위도 |
| lng | 숫자 | 경도 |

### 방문 대상자 (Resident)

| 필드 | 타입 | 설명 |
|---|---|---|
| id | 문자열 | 고유 식별자 |
| name | 문자열 | 이름 |
| address | 문자열 | 주소 |
| checkedIn | 불리언 | 오늘 확인 여부 |
| checkedInAt | 날짜시간 (없을 수 있음) | 체크한 시각 |

## 4. 이번에 만들지 않을 것

- 로그인 / 회원가입 / 봉사자 인증
- 관리자 대시보드 (미확인자 알림 기능) — 다음 단계로 미룸
- 혼잡도 표시 (plan.md에서 이미 제외)
- 실제 지자체 공공데이터 연동 (이번엔 예시 데이터로 대체)
- 데이터베이스 연동 (Supabase 등) — 이번엔 예시 데이터로 화면만 확인
