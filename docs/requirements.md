# 요구사항 명세

기준 문서: docs/plan.md (폭염지킴이)
이번 라운드 범위: 근처 쉼터 찾기 화면(네이버 지도 연동)

(체크인 화면은 방향 전환으로 제거함)

## 1. 화면 목록

### ① 근처 쉼터 찾기 화면 (메인)
- "근처 무더위쉼터 찾기" 버튼 하나가 보임
- 버튼을 누르면 브라우저가 현재 위치 권한을 요청함
- 위치를 확인하면 새 탭에서 네이버 지도의 "무더위쉼터" 검색 결과를 현재 위치 근처로 열어줌
- 위치 확인이 안 되면 위치 없이 전체 검색 결과를 열어줌
- 네이버 지도 API 키가 필요 없음 (네이버 지도 웹 검색 링크로 연결하는 방식)
- 로그인 없이 누구나 접근 가능

## 2. 기능 목록 (사용자가 할 수 있는 행동)

- "근처 무더위쉼터 찾기" 버튼을 누른다
- 위치 권한을 허용하면 네이버 지도에서 근처 쉼터 검색 결과를 새 탭으로 본다

## 3. 데이터

이 화면은 네이버 지도 검색으로 바로 연결되기 때문에, 저장하는 데이터가 없음.

## 4. 이번에 만들지 않을 것

- 로그인 / 회원가입
- 체크인, 관리자 대시보드 (방향 전환으로 제거)
- 네이버 지도 API 직접 연동 (Client ID 발급, Dynamic Map, Directions API) — 대신 네이버 지도 웹 검색 링크로 대체
- 실제 지자체 공공데이터 연동
- 데이터베이스 연동 (Supabase 등)
