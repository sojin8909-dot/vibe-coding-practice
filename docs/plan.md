# 기획서

## 서비스 이름

폭염지킴이

(가제. 마음에 안 들면 바꿀 수 있음)

## 문제 정의

낙후 지역의 고령자·교통약자는 에어컨 보급률이 낮아 여름철 열사병 위험이 크다. 진주시가 운영하는 경로당·동/주민센터 같은 무더위쉼터가 있지만 위치 정보가 흩어져 있어 접근이 어렵고, 혼자 지내는 고령자의 안전 상태를 주변에서 즉시 확인하기 어렵다.

이 서비스는 교통약자가 낮은 정보 접근성 때문에 이미 마련된 시설을 이용하지 못하는 문제를, 하드웨어를 새로 짓지 않고 정보 접근을 쉽게 만드는 소프트웨어로 보완하려 한다.

## 타겟 사용자

- **직접 이용자 (화면을 보고 조작하는 사람)**: 자원봉사자, 지자체/복지 담당자
- **간접 수혜자 (도움을 받는 사람, 화면을 직접 조작하지 않음)**: 에어컨이 없는 고령자·교통약자

## 핵심 기능 3개

1. **무더위쉼터 위치 지도** — 진주시 경로당·동/주민센터 위치를 지도에 표시 (혼잡도 표시는 이번 버전에서 제외, 위치 정보만 제공)
2. **안부 확인 체크인** — 봉사자가 방문 대상자 목록에서 방문 후 "확인 완료"를 체크하고, 체크 시각을 기록
3. **미확인자 알림 대시보드** — 정해진 시간까지 체크가 안 된 대상자를 관리자 화면에서 한눈에 볼 수 있게 표시

## 화면 구성

1. 쉼터 지도 화면 — 누구나 접근 가능
2. 봉사자용 방문 대상자 목록 화면 — 로그인 필요, 체크인 버튼 포함
3. 관리자 대시보드 화면 — 오늘 체크 현황, 미확인자 강조 표시
