# 기획서

## 서비스 이름

폭염지킴이

(가제. 마음에 안 들면 바꿀 수 있음)

## 문제 정의

낙후 지역의 고령자·교통약자는 에어컨 보급률이 낮아 여름철 열사병 위험이 크다. 진주시가 운영하는 경로당·동/주민센터 같은 무더위쉼터가 있지만 위치 정보가 흩어져 있어 접근이 어렵고, 혼자 지내는 고령자의 안전 상태를 주변에서 즉시 확인하기 어렵다.

이 서비스는 교통약자가 낮은 정보 접근성 때문에 이미 마련된 시설을 이용하지 못하는 문제를, 하드웨어를 새로 짓지 않고 정보 접근을 쉽게 만드는 소프트웨어로 보완하려 한다.

## 타겟 사용자

- **직접 이용자 (화면을 보고 조작하는 사람)**: 자원봉사자, 지자체/복지 담당자
- **간접 수혜자 (도움을 받는 사람, 화면을 직접 조작하지 않음)**: 에어컨이 없는 고령자·교통약자

## 핵심 기능

1. **근처 시설 찾기 (무더위쉼터 / 동사무소 / 면사무소 / 시청 / 버스정류장)** — 버튼 한 번 누르면 현재 위치 기준으로 네이버 지도에서 해당 시설을 바로 찾아줌 (자체 지도 대신 네이버 지도로 연결, API 키 없이 동작)
2. **오늘 폭염특보 확인** — 기상청 폭염 특보 페이지로 바로 연결
3. **서류 발급 안내** — 자주 찾는 공인문서 10종의 필요한 것/발급 방법/발급 창구 안내
4. **긴급 연락처** — 119, 112, 치매상담콜센터, 보건복지상담센터로 바로 전화

(안부 확인 체크인, 관리자 대시보드는 방향 전환으로 제거함)

## 화면 구성

1. 메인 화면 — "오늘 폭염특보 확인" 버튼, "근처 OO 찾기" 버튼 5개(무더위쉼터/동사무소/면사무소/시청/버스정류장), "서류 발급" 섹션, "거리순으로 보는 방법" 안내, "긴급 연락처" 섹션(119/112/치매상담콜센터/보건복지상담센터), 네이버 지도 앱 설치 링크. 누구나 접근 가능
